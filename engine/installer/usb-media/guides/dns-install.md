# Debian OS + DNS 설치

이 USB의 `Debian OS + DNS 서버 설치` 항목은 Debian 운영체제와 DNS 서비스를 함께 설치합니다. 장비 정보 수집용 Debian Live USB와 구별하세요.

1. HP에 유선 LAN과 USB를 연결하고 USB로 부팅합니다. 설치 항목은 직접 선택합니다.
2. 안내형(guided) 이미지에서는 `dns01`, `dns02`, `dns03` 역할과 연결한 유선 LAN을 선택합니다. 한 장비에 한 역할을 사용합니다.
3. 표시된 주소·게이트웨이와 내부 디스크의 모델·일련번호·용량을 확인합니다. 화면의 `ERASE …` 문구를 정확히 입력하면 해당 내부 디스크의 모든 데이터를 삭제합니다.
4. Debian 설치를 완료하고 내부 디스크로 재부팅합니다. 첫 부팅의 DNS 설정과 암호화된 등록 기록 저장이 끝날 때까지 USB를 연결해 둡니다. 다시 USB 설치 메뉴로 들어가지 마세요.
5. 관리 호스트에서 `dns01`의 DNS·관리 접속·등록 기록 복구를 검증한 뒤 나머지 장비를 한 대씩 설치합니다. Tailscale 등록과 세 대의 클러스터 구성은 관리 호스트에서 이어서 진행합니다.

내부 디스크가 여러 개이거나, USB·사용 중인 디스크가 대상이면 설치를 중단합니다. 검사 오류를 피하려고 해시나 디스크 정보를 수정하지 마세요. 이미 등록이 완료된 역할을 다시 설치하려면 해당 세대에 연결된 별도 재설치 승인이 필요합니다.

현재 기본 주소는 `dns01=10.0.5.1`, `dns02=10.0.5.2`, `dns03=10.0.5.3`, 게이트웨이는 `10.0.0.1/16`입니다. `192.168.0.x` 공유기에 이 설정을 그대로 설치하지 마세요. 공유기 DHCP DNS 변경은 세 대의 정상 동작을 확인한 뒤 마지막에 합니다.

이 가이드는 설치 성공 증거가 아닙니다. 관리 호스트에서 해당 이미지의 BIOS·UEFI 설치 검증과 물리 장비 검증 상태를 먼저 확인하세요.

Reviewed 이미지에서는 사전에 검토한 장비 인벤토리와 정확히 일치하는 한 역할만 설치할 수 있습니다. 안내형 이미지는 각 장비에서 직접 식별·확인하므로 정보 수집 후 USB를 다시 굽는 과정이 필요 없습니다.
